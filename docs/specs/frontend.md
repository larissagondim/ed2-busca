# Especificação: interface web genérica

A interface React permite selecionar período, paginar, pesquisar ID/código, abrir detalhes, comparar as oito estratégias e consultar/reiniciar o resumo. Mostra carregamento, vazio e erro; funciona por teclado; possui foco visível, rótulos e HTML semântico. O visual é neutro e responsivo, sem identidade definitiva ou animação decorativa.

## Aceitação

- Ao carregar, período, grade e paginação são operáveis.
- Ao buscar ID/código, detalhes e comparação aparecem ou um erro acessível é anunciado.
- Em tela estreita não há rolagem horizontal da página.
